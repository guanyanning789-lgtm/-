# IELTS Daily 5H

一个面向 IELTS 基础阶段的本地桌面学习 App。

## 当前版本：V0.1

已经具备：

- Day 1 完整 5 小时学习流程
- 20 个高频基础词汇
- 单字 / 语法 / 听力 / 阅读 / 口语 / 写作五个模块
- 每小时完成打卡
- 本地保存学习进度
- 晚上记录错题和弱项
- 根据“时态 / 动词 / 单字”等问题生成 Day 2 的重点方向
- Windows 双击启动

## 启动方式

1. 下载或克隆本仓库。
2. 确保 Windows 已安装 Python。
3. 双击 `启动 IELTS 学习 App.bat`。

程序不需要额外第三方 Python 包，使用 Tkinter 运行。

## 下一阶段：V0.2

目标不是继续写死 Day 2，而是建立连续 60 天学习引擎：

- 保存每日完成情况
- 保存不熟单字和错题
- 保存语法、写作、口语弱项
- 自动安排间隔复习
- 根据上一天表现生成下一天 5 小时内容
- 建立 Today 首页和学习进度仪表板

## 后续路线

- V0.3：AI Teacher，可随时提问
- V0.4：口语录音与语音对话
- V0.5：IELTS 真题 / 资料索引
- V0.6：Writing / Speaking 自动批改
- V0.7：目标分数与学习进度预测
- V1.0：完整个人 IELTS AI 学习系统

## 数据

学习记录默认保存在程序目录中的 `study_progress.json`，属于本地个人数据，不应提交到 GitHub。
